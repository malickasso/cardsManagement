```bash
composer install && npm install

```

## Architecture

**Stack:** Laravel 12, PostgreSQL, Tailwind CSS, Alpine.js, Vite, Spatie Laravel Permission.

### User Hierarchy

```
Admin  (guard: admin, model: Admin, table: admins)
  └─ Grossiste  (guard: web, UserDetail.type_user = 'GROSSISTE', created by Admin)
       └─ Partenaire  (guard: web, UserDetail.type_user = 'PARTENAIRE', created by Grossiste)
```

Both Grossiste and Partenaire share a single `UserDetail` model/table (`users_details`), differentiated by the `type_user` enum. The `Admin` model uses a separate table (`admins`) and a separate auth guard (`admin`).

Custom password field: both models use `mot_de_passe` (not `password`) and override `getAuthPassword()`.

### Routes

Three route files loaded in `bootstrap/app.php`:
- `routes/web.php` — main app routes (admin, grossiste, partenaire groups)
- `routes/auth.php` — user login/register/password/verification
- `routes/admin-auth.php` — admin login/register

Route groups by prefix and guard:
| Prefix | Guard | Middleware |
|--------|-------|------------|
| `/admin` | `auth:admin` | — |
| `/grossiste` | `auth:web` | `user.type:grossiste` |
| `/partenaire` | `auth:web` | `user.type:partenaire` |

### Middleware

`CheckUserType` (`app/Http/Middleware/CheckUserType.php`) — enforces `UserDetail.type_user`. Registered as alias `user.type` in `bootstrap/app.php`.

### Key Models

| Model | Table | Notes |
|-------|-------|-------|
| `Admin` | `admins` | Admin guard, HasRoles |
| `UserDetail` | `users_details` | Default web guard, HasRoles, unified Grossiste/Partenaire |
| `Banque` | `banque` | Banks, `statut` enum (ACTIF/INACTIF) |
| `TypeCarte` | `type_carte` | Card types, linked to Admin creator |
| `Carte` | `carte` | Cards — FK to TypeCarte, Banque, and Grossiste (UserDetail) |

`Grossiste` and `Partenaire` models/tables are legacy and superseded by `UserDetail`.

UUIDs are generated by PostgreSQL `gen_random_uuid()` in migrations.

### Controllers

```

├── Admin/

│   ├── Auth/RegisteredUserController.php

├── Grossiste/

```

### Views

Blade views under `resources/views/` organized by role: `admin/`, `grossiste/`, `partenaire/`, plus shared `layouts/`, `components/`, `partials/`.

### Environment

- **Database:** PostgreSQL on port 5432, database `cardmanagement`
- **Session/Cache/Queue:** all use `database` driver
- **Mail:** `log` driver in development
